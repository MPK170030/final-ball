# CaptainCard

The captain pick, vice-captain and 1–2 alternatives, each with a one-line reason (D4.1).

## Rules
- The captain block is the card's single emphasis: orange border plus the filled orange **C** badge. The vice gets an outlined **V**.
- Picks consider the squad after the suggested transfer (D4.4), so the incoming player can appear here; say so in the reason when it does.
- Fixture shown as "vs ARS (H)" in the meta line; no chips here.
- **Why?** opens the DetailSheet for the captain (Why tab).

## Consumer provides
Captain, vice and alternatives with club, opponent, home/away and reason.
